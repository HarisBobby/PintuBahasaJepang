Cara pasang (butuh HTTPS):
1. Upload SEMUA isi folder ini ke hosting statis (GitHub Pages / Netlify / Cloudflare Pages), satu folder.
2. Buka URL-nya di Chrome (Android) -> menu -> Instal aplikasi. Di iPhone: Safari -> Bagikan -> Tambahkan ke Layar Utama.
Kalau update index.html, ubah angka V di sw.js (pbj-v2 -> pbj-v3) supaya cache diperbarui.
